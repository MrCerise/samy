# `/birthday`

`slash`

View, set, or list user birthdays.

## `/birthday set`

`slash`

Set your birthday.

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `date` | — | Your birthday (MM/DD/YYYY, MM/DD, or May 15). | true |

## `/birthday get`

`slash`

View birthday of a user.

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | — | The user whose birthday to view. | false |

## `/birthday upcoming`

`slash`

List upcoming birthdays in the server.

## `/birthday unset`

`slash`

Remove your saved birthday.
