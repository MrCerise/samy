# `builder`

`prefix`

**Aliases:** `build`, `b`

Build and send a text, embed, or Components V2 message.

**Usage**
```
,builder <message>
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `message` | `m` | Plain text, an {embed} script, or a {cv2} script. | false |

## `builder copy`

`prefix`

**Aliases:** `info`, `source`

Copy a message into builder script syntax.

**Usage**
```
,copy [message]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `message` | `link`, `url` | A Discord message link. You can also reply to a message. | false |
