# `emojiinfo`

`prefix`

**Aliases:** `ei`, `emoji`

Get information about an emoji.

**Usage**

```
,emojiinfo <emoji>
```

| Argument | Aliases | Description                        | Required |
| :------- | :------ | :--------------------------------- | :------: |
| `emoji`  | `e`     | The emoji to get information about |  false   |
