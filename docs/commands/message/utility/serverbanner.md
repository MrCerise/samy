# `serverbanner`

`prefix` `guild only`

**Aliases:** `guildbannerbg`, `serverbannerbg`

View a user's server-specific banner.

**Usage**
```
,serverbanner [user]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u` | The user to get the server banner from | false |
