# `birthday`

`prefix`

**Aliases:** `bday`, `bd`

View, set, or list user birthdays.

**Usage**
```
,birthday [target]
```

| Argument | Description | Required |
| :-- | :-- | :--: |
| `target` | The user whose birthday you want to view. | false |

## `birthday set`

`prefix`

Set your birthday.

**Usage**
```
,set <date>
```

| Argument | Description | Required |
| :-- | :-- | :--: |
| `date` | Your date of birth (MM/DD/YYYY, MM/DD, or May 15). | false |

## `birthday unset`

`prefix`

**Aliases:** `remove`, `clear`

Remove your saved birthday.

**Usage**
```
,unset
```

## `birthday list`

`prefix`

**Aliases:** `upcoming`

List upcoming birthdays in the server.

**Usage**
```
,list
```

## `birthday get`

`prefix`

View birthday of a user.

**Usage**
```
,get [target]
```

| Argument | Description | Required |
| :-- | :-- | :--: |
| `target` | The user to view birthday for. | false |
