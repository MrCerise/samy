# `timediff`

`prefix`

**Aliases:** `snowdiff`, `timebetween`

Calculate the time difference between two Discord snowflake IDs.

**Usage**
```
,timediff <snowflake1> <snowflake2>
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `snowflake1` | `first`, `a` | The first Discord snowflake ID. | false |
| `snowflake2` | `second`, `b` | The second Discord snowflake ID. | false |
