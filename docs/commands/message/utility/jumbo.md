# `jumbo`

`prefix`

**Aliases:** `enlarge`, `bigemoji`, `jumboemoji`

Enlarge a custom emoji.

**Usage**

```
,jumbo <emoji>
```

| Argument | Aliases | Description           | Required |
| :------- | :------ | :-------------------- | :------: |
| `emoji`  | `e`     | The emoji to enlarge. |  false   |
