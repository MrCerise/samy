# `charinfo`

`prefix`

**Aliases:** `char`, `character`

Get information about a character (codepoint, UTF-8, etc.).

**Usage**

```
,charinfo <character>
```

| Argument    | Aliases | Description               | Required |
| :---------- | :------ | :------------------------ | :------: |
| `character` | `char`  | The character to inspect. |  false   |
