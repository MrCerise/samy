# `lastfm`

`prefix`

**Aliases:** `fm`

View your Last.fm profile, recent tracks, and overall statistics

**Usage**
```
,lastfm [user]
```

| Argument | Description | Required |
| :-- | :-- | :--: |
| `user` | A Discord user (mention or ID) to view. | false |

## `lastfm link`

`prefix`

Link your Last.fm profile to the bot

**Usage**
```
,link <username>
```

| Argument | Description | Required |
| :-- | :-- | :--: |
| `username` | Your Last.fm username. | false |

## `lastfm unlink`

`prefix`

Remove your linked Last.fm account

**Usage**
```
,unlink
```
