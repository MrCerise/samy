# `serveravatar`

`prefix` `guild only`

**Aliases:** `guildavatar`, `serverpfp`, `guildpfp`

View a user's server-specific avatar.

**Usage**
```
,serveravatar [user]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u` | The user to get the server avatar from | false |
