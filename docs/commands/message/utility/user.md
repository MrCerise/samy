# `user`

`prefix`

**Aliases:** `userinfo`, `u`, `whois`

Get information about a user

**Usage**

```
,user [user]
```

| Argument | Aliases | Description                          | Required |
| :------- | :------ | :----------------------------------- | :------: |
| `user`   | `u`     | The user to get the information from |  false   |
