# `roleinfo`

`prefix` `guild only`

**Aliases:** `ri`

Get information about a role.

**Usage**

```
,roleinfo <role>
```

| Argument | Aliases | Description                       | Required |
| :------- | :------ | :-------------------------------- | :------: |
| `role`   | `r`     | The role to get information about |  false   |
