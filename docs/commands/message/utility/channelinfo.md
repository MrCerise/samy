# `channelinfo`

`prefix` `guild only`

**Aliases:** `ci`

Get information about a channel.

**Usage**

```
,channelinfo [channel]
```

| Argument  | Aliases | Description                          | Required |
| :-------- | :------ | :----------------------------------- | :------: |
| `channel` | `c`     | The channel to get information about |  false   |
