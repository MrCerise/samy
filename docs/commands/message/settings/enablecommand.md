# `enablecommand`

`prefix` `guild only`

**Requires:** ManageGuild

Enable a command in this server.

**Usage**

```
,enablecommand <command>
```

| Argument  | Aliases | Description            | Required |
| :-------- | :------ | :--------------------- | :------: |
| `command` | —       | The command to enable. |  false   |
