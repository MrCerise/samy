# `prefix`

`prefix` `guild only`

View or manage the server and user prefix.

**Usage**
```
,prefix
```

## `prefix add`

`prefix`

Set a custom prefix.

**Usage**
```
,add
```

## `prefix remove`

`prefix`

Remove a custom prefix.

**Usage**
```
,remove
```

## `prefix view`

`prefix`

View the current prefix.

**Usage**
```
,view
```
