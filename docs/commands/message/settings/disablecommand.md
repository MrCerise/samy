# `disablecommand`

`prefix` `guild only`

**Requires:** ManageGuild

Disable a command in this server.

**Usage**

```
,disablecommand <command>
```

| Argument  | Aliases | Description             | Required |
| :-------- | :------ | :---------------------- | :------: |
| `command` | —       | The command to disable. |  false   |
