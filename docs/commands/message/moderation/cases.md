# `cases`

`prefix` `guild only`

**Aliases:** `case`

**Requires:** ManageMessages, ModerateMembers

View and manage moderation cases.

**Usage**
```
,cases [user] [case_number] [page]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u`, `member`, `target` | The user to view cases for. | false |
| `case_number` | `case`, `id`, `number` | Specific case number to view. | false |
| `page` | `p` | Page number. | false |
