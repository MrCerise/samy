# `timeout`

`prefix` `guild only`

**Aliases:** `mute`, `to`

**Requires:** ModerateMembers

Timeout a user, preventing them from interacting in the server.

**Usage**
```
,timeout <user> [duration] [reason]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u`, `member`, `target` | The user to timeout. | false |
| `duration` | `d`, `time`, `t` | Duration of the timeout (e.g. 10m, 1h, 7d). Max 28 days. | false |
| `reason` | `r` | Reason for the timeout. | false |
