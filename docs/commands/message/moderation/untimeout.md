# `untimeout`

`prefix` `guild only`

**Aliases:** `unmute`, `uto`

**Requires:** ModerateMembers

Remove a user's timeout.

**Usage**
```
,untimeout <user> [reason]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u`, `member`, `target` | The user to remove the timeout from. | false |
| `reason` | `r` | Reason for removing the timeout. | false |
