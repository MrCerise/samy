# `ban`

`prefix` `guild only`

**Requires:** BanMembers

Ban a user, optionally with a duration.

**Usage**

```
,ban <user> [reason]
```

| Argument | Aliases                 | Description                                                                                   | Required |
| :------- | :---------------------- | :-------------------------------------------------------------------------------------------- | :------: |
| `user`   | `u`, `member`, `target` | The user to ban.                                                                              |  false   |
| `reason` | `r`                     | Optional duration (e.g. 1d, 12h) followed by a reason. E.g. `1d spamming` or just `spamming`. |  false   |
