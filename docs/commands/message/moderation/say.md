# `say`

`prefix` `guild only`

**Requires:** ManageMessages

Send a message as the bot to a channel.

**Usage**
```
,say <message>
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `message` | `m` | Plain text, or an {embed}/{cv2} script. Optionally start with a #channel mention. | false |
