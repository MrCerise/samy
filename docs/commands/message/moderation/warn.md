# `warn`

`prefix` `guild only`

**Aliases:** `warning`

**Requires:** ModerateMembers

Warn a user.

**Usage**
```
,warn <user> [reason]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `user` | `u`, `member`, `target` | The user to warn. | false |
| `reason` | `r` | Reason for the warning. | false |
