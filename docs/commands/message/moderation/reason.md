# `reason`

`prefix` `guild only`

**Aliases:** `editreason`, `casereason`

**Requires:** ModerateMembers

Edit the reason of a moderation case.

**Usage**

```
,reason <case_number> <reason>
```

| Argument      | Aliases                | Description                  | Required |
| :------------ | :--------------------- | :--------------------------- | :------: |
| `case_number` | `case`, `id`, `number` | The case number to edit.     |  false   |
| `reason`      | `r`                    | The new reason for the case. |  false   |
