# `kick`

`prefix` `guild only`

**Aliases:** `k`

**Requires:** KickMembers

Kick a user.

**Usage**

```
,kick <user> [reason]
```

| Argument | Aliases                 | Description          | Required |
| :------- | :---------------------- | :------------------- | :------: |
| `user`   | `u`, `member`, `target` | The user to kick.    |  false   |
| `reason` | `r`                     | Reason for the kick. |  false   |
