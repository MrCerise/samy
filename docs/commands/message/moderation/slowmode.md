# `slowmode`

`prefix` `guild only`

**Requires:** ManageChannels

Set the slowmode delay for a channel.

**Usage**
```
,slowmode <duration> [channel]
```

| Argument | Aliases | Description | Required |
| :-- | :-- | :-- | :--: |
| `duration` | `time`, `delay` | Slowmode duration (e.g. 10s, 5m, 1h, or 0 to disable). Maximum 6 hours. | false |
| `channel` | `c` | The channel to change (defaults to this channel). | false |
