# `unban`

`prefix` `guild only`

**Aliases:** `ub`

**Requires:** BanMembers

Unban a user.

**Usage**

```
,unban <user> [reason]
```

| Argument | Aliases                 | Description               | Required |
| :------- | :---------------------- | :------------------------ | :------: |
| `user`   | `u`, `member`, `target` | The user to unban.        |  false   |
| `reason` | `r`                     | The reason for the unban. |  false   |
