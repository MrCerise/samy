# `samy`

`prefix`

Get a random picture of Samy.

**Usage**

```
,samy
```

## `samy add`

`prefix` `owner only`

Add a new Samy picture.

**Usage**

```
,add <url>
```

| Argument | Aliases            | Description                         | Required |
| :------- | :----------------- | :---------------------------------- | :------: |
| `url`    | `image`, `picture` | The direct URL of the Samy picture. |  false   |

## `samy remove`

`prefix` `owner only`

**Aliases:** `delete`, `del`

Remove a Samy picture.

**Usage**

```
,remove <id>
```

| Argument | Aliases | Description                           | Required |
| :------- | :------ | :------------------------------------ | :------: |
| `id`     | `image` | The ID of the Samy picture to remove. |  false   |

## `samy list`

`prefix` `owner only`

**Aliases:** `all`

List all Samy pictures.

**Usage**

```
,list
```
